# 汉字拼拼乐

给中文课堂的拆字重组集体游戏。

## 它做什么

老师把一课的生字录进课堂，系统按随应用托管的拆字资料把每个字拆成部件（「明」→「日」+「月」）。学生在手机或电脑上把打乱的部件拖进拼字区、按左右或上下摆好再提交，系统按部件顺序与结构判对错。一个房间号，全班同时玩。

## 适合谁

- 国际中文课堂的老师：需要课前 3 分钟备一课生字、课中投屏看全班状态、课后拿到逐字报告。
- 课堂上的学生：不想注册账号，输入房间号和昵称就开始。
- 课后复习的学生：打开本课练习链接，不需要老师在场。

## 怎么用

1. 老师打开教师端 → 创建课堂 → 生成房间号 → 粘贴或从字库勾选字表 → 保存并开始上课。
2. 学生打开学生端 → 输房间号与昵称 → 把部件摆成目标字 → 提交。
3. 老师看状态墙：谁已对、谁卡住、谁求助，五色格子一眼看完。
4. 结束后看成绩报告：班级四指标、个人榜、按字查（卡住 / 求助 / 第 3 次才对 / 提示后仍错），可导出 CSV。
5. 课后把练习链接发到班级群，学生自己练这一课的生字。

## 值得注意的地方

- 判分不是选择题：要看部件对不对、摆放方向对不对、顺序对不对，包围结构还要看内件有没有落在外框里。
- 答错不扣分，第 3 次才给结构提示；求助会实时出现在老师的屏幕上。
- 老师可以改任一个字的拆法（含把某个部件锁成整块），改一次对该老师的所有课堂生效。
- 积分：答对 +10，一次答对 +15，看过提示或求助后答对 +5。

## 提示词

我想在中文课上带学生练这一课的生字，用「汉字拼拼乐」：

- 建一个课堂，房间号用这节课的课次，比如 HSK1L3；
- 字表放 5 到 8 个本课生字；
- 上课时投屏状态墙，看到有学生卡住就点「下一题」往下走；
- 下课前结束本局，把成绩报告导出 CSV，看看哪几个字要下节课再讲；
- 把课后练习链接发到班级群，让学生回家再练一遍。

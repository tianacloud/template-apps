# 玩法与规则

## 1. 一局课的流程

```
老师建课堂（录字表） → 老师「开始上课」 → 学生加入 → 逐题拼字
      ↑                                              ↓
      └──────── 老师切题 / 学生自己往下做 ←──────────┘
                                        ↓
                              老师「结束本局」→ 成绩报告
```

课堂状态三态：`lobby`（未开始）、`playing`（进行中）、`ended`（已结束）。

- 未开始时学生看到「课堂还没开始」，页面每 4 秒轮询一次状态。
- 进行中老师可以「上一题 / 下一题」，切换会重置全班当前题号。
- 学生可以越过老师的进度自己往下做，顶栏出现「预览」标记；老师切题时学生归位到老师指定的题号。
- 结束后学生看到「本局已结束」，老师可以生成报告。

## 2. 拆字规则

### 2.1 部件来源

每个字的拆解由随应用分发的字典给出，字段：

| 字段 | 含义 |
| --- | --- |
| `m` | 模式：`A` 可拆、`B` 可拆（含整块锁定件）、`C` 独体字 |
| `p` | 部件数组，按书写顺序 |
| `lk` | 锁定部件：该件在游戏里作为整块出现，不再拆开 |
| `n` | 部件数 |
| `st` | 结构标签（左右结构 / 上下结构 / 左中右结构 / 上中下结构 / 半包围结构 / 全包围结构 / 独体字） |
| `s` | 表意文字描述序列（IDS），用于判定部件顺序与包围关系 |
| `py` / `en` | 拼音 / 英文释义，答对时展示 |
| `r` | 拆解理由（用于教师端说明） |

### 2.2 可玩判定

- 模式 `C`（独体字）与字典未收录的字**不可玩**：学生端显示「这个字不拆分，可以直接跳过」，教师端 chip 显示「独」角标。
- 模式 `A` / `B` 且部件数 ≥ 2 才进入拼字。

### 2.3 教师覆盖

老师可以点开任一字块修改拆法：选数据源拆解或自定义部件数、逐个锁定部件、选择结构标签。覆盖保存在 `char_overrides`，对该老师的**所有课堂**生效（全局配置页可见），并可一键恢复系统拆法。

## 3. 判分规则

判分完全在浏览器内完成，不请求服务端。

给定学生已放下的部件集合 `placed` 与目标 `plan`：

1. **数量**：`placed.length === plan.parts.length`，否则不通过（提交按钮此时禁用）。
2. **多重集**：已放部件的字符多重集必须与目标一致（不能把「日」放两次代替「月」）。
3. **排布方向**：由所有已放部件的**中心点**推出 formation ——
   - `spanY > spanX` → `tb`（上下），否则 `lr`（左右）。
4. **顺序**：按 formation 排序后的字符序列必须与 IDS 叶子序列一致。
   - `lr`：按 `cx` 升序；`tb`：按 `cy` 升序。
5. **结构标签**：若结构标签含「左右 / 左中右」则 formation 必须是 `lr`，含「上下 / 上中下」则必须是 `tb`；结构标签为空时跳过此项。
6. **包围结构特例**：IDS 根操作符为包围类（`⿴⿵⿶⿷⿸⿹⿺`）时，改为判断内部部件的**中心点是否落在外部件矩形内**（容差 6px），不再比较顺序。

判定通过 → 记一次正确提交；不通过 → 记一次错误提交，不扣分。

## 4. 计分

| 情形 | 得分 |
| --- | --- |
| 答对 | +10 |
| 一次就答对（`attempts === 1`） | +15（替代 +10，不叠加） |
| 看过提示或点过求助后答对 | +5 |
| 答错 | 0 |

同一学生对同一字只保留最后一次提交（`answers` 以 `room_code + student_id + char_index` 为主键做 UPSERT）。

排行榜排序：分数 → 答对数 → 累计用时（用时权重最低）。范围（全部课堂 / 本课堂）× 周期（累计 / 本周 / 本月）。

## 5. 提示与求助

| 触发 | 行为 |
| --- | --- |
| 第 1 次答错 | 提示「再试一次」，可继续摆放 |
| 第 3 次答错 | 给出结构提示（左右/上下 + 是否有整块锁定件），并提示「4 秒后自动进入下一题」，同时提供「我还能再试试，留在本题」 |
| 点求助按钮 ✋ | 向老师发一次求助信号，状态墙该学生变红，个人榜求助次数 +1 |
| 主动看提示后答对 | 计分降为 +5 |

## 6. 状态墙的五态

| 状态 | 判定 | 颜色 |
| --- | --- | --- |
| 未开始 `idle` | 本局还没轮到他 / 还没加入 | 灰紫 `#4a4a7a` |
| 进行中 `trying` | 在线但当前题未答对 | 蓝 `#60a5fa` |
| 卡住 `stuck` | 当前题错误次数 ≥ 2 | 黄 `#fbbf24` |
| 求助 `help` | 点过求助且本题未答对 | 红 `#f87171` |
| 已对 `done` | 当前题已答对 | 绿 `#4ade80` |

在线判定：学生页每 8 秒心跳一次，超过 30 秒无心跳视为离线。

## 7. 课后练习

- 有课堂：练习该课堂本课生字，题序随机。
- 无课堂：自选字库字集，或粘贴自定义汉字。
- 完成一题即写入 `practice_records`（不含身份信息，只记字、是否正确、尝试次数、用时）。
- 老师端「自主练习」按 7 / 30 / 90 天窗口统计，并列出「课后最难练的字」。

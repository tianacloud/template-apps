# 产品规格 · 汉字拼拼乐

## 1. 产品定位

面向国际中文课堂的**拆字重组集体识字游戏**。

老师把一课的生字录进课堂，学生用手机把汉字部件拼回目标字；老师在大屏上实时看到全班每道题的进展，课后拿到「哪个字全班最卡、谁在第几次才对」的成绩报告。

产品解决三件事：

1. **集体参与**：一个房间号，全班同时答题，不需要安装、不需要注册。
2. **结构意识**：学生不是选字，而是把「日」和「月」摆成「明」，练习的是汉字的间架结构。
3. **教学反馈**：老师拿到的是逐字、逐人的错误分布，而不是一个总分。

## 2. 使用者

| 角色 | 场景 | 需要的能力 |
| --- | --- | --- |
| 老师 | 课前备课、课中投屏、课后复盘 | 建课堂、录字表、控节奏、看状态墙、导出报告 |
| 学生 | 课中在自己手机上答题 | 输房间号 + 昵称即进、拖拽拼字、看提示、求助 |
| 学生（课后） | 回家复习本课生字 | 打开练习链接，自主练习，不需要老师在场 |

老师与学生都不需要账号密码：老师身份来自平台登录态，学生身份是房间内的一次性昵称。

## 3. 功能范围

### 3.1 首页

- 站点统计条：注册老师数、参与过课堂的学生数、课堂数、课后练习次数（实时读取数据库）。
- 三张入口卡：我是学生 / 我是老师 / 已有游戏室号码。
- 老师卡另有「字库」次级入口。

### 3.2 教师端

| 页面 | 功能 |
| --- | --- |
| 教师中心 | 显示当前登录身份与称呼（可改）；创建课堂、档案馆、字库、进入已有课堂 |
| 创建课堂 | 生成房间号（可手填）、从字库勾选字表、或直接粘贴任意汉字；勾选数据处理声明后创建 |
| 课堂控台 | 六个标签页，见下 |
| 档案馆 | 列出自己的课堂：房间号、名称、创建时间、字数、状态；可打开控台、导出 |
| 字库 | 我的字集与共享字集；导入新字集（名称、分类、字表）；查看、共享、删除 |

控台六标签：

1. **课堂设置** — 课堂名称；课后练习链接（复制/试一下）；生字表（粘贴或手写输入）；本轮字表（逐字 chip，带模式角标与结构说明，可点开改拆解）；教学顺序与课次；部件课堂名（N2 起）；组字故事（N3 起）；保存设置 / 保存并开始上课；上课后追加上一题 / 下一题 / 结束本局。
2. **状态墙** — 当前题目大字与进度；在线/已对/卡住/求助/进行中五态统计；学生网格（昵称 + 答对数，按状态配色）；结束本局并生成报告。
3. **成绩报告** — 四格班级指标；个人榜；按字查 / 按人查切换；刷新；导出 CSV。
4. **排行榜** — 范围（全部课堂 / 本课堂）× 周期（累计 / 本周 / 本月）的积分榜，附计分说明。
5. **自主练习** — 7 / 30 / 90 天窗口的四格指标；课后最难练的字；清理 30 天前记录。
6. **全局配置** — 该老师跨课堂生效的组字故事与拆解覆盖。

### 3.3 学生端

- **入口**：输入房间号进入；或在游戏页直接输昵称加入。
- **游戏页**：顶栏（昵称 / 进度 / 计时）；上一题 / 回到当前 / 下一题；拼字区 + 部件托盘；提交（未满时显示「还差 N 块」）；清空重来；求助按钮；排行榜。
- **答对**：浅色反馈卡覆盖拼字区 —— ✓ 答对了、进度、大字本字、拼音、英文释义、`部件 + 部件 = 本字`、2 秒后自动下一题、底部倒计时条。
- **答错**：不扣分，提示再试；第 3 次尝试给出结构提示；提示后可选择「我还能再试试」或等 4 秒自动进入下一题。
- **超前作答**：学生做完当前题可以继续往下做，顶栏出现「预览」标记，老师进度跟上时自动归位。
- **课后练习**：有课堂时练本课生字；无课堂时自选字库或粘贴自定义字；结束上报练习记录。

## 4. 明确的边界

- 不提供账号注册、密码、邮件验证。
- 不提供跨班级的实时协同编辑；同一课堂的状态同步是轮询，不是长连接。
- 不提供图片上传（课堂背景主题）。
- 不提供手写识别（手写输入仅作为文本录入的替代入口时移除）。
- 不提供支付、订阅或任何收费能力。
- 不内置题库；字表由老师录入或从字库选取，拆字数据随应用分发。

## 5. 验收场景

1. 老师登录 → 创建课堂（4 个字）→ 开始上课。
2. 学生用房间号 + 昵称加入 → 看到第 1 题 → 拼对 → 反馈卡 → 自动进入第 2 题。
3. 学生第 2 题故意拼错 → 提示 → 第 3 次给结构提示 → 答对。
4. 老师在状态墙看到该学生的状态从「进行中」变为「已对」，答对数递增。
5. 老师结束本局 → 成绩报告显示参与人数、正确率、攻下字数、求助次数与逐字分布 → 导出 CSV。
6. 刷新页面，课堂、答案、报告数据仍在。
7. 学生打开课后练习链接，练本课生字，完成后记录入库。
8. 桌面与移动视口都能完成上述 1–7。

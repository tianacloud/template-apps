# 一起出发 · 团建活动

一个围绕团队聚餐的可编辑 Web 应用。用各自的 Tiana 登录身份组织活动、推荐餐厅、投票和讨论；默认打开最近创建且未关闭的活动。

## 功能

- 活动名称、聚餐时间、集合地点、出发时间和注意事项默认展示为文字，点击铅笔编辑。编辑记录位于页面底部，默认折叠。
- 所有参与者可添加、修改、删除餐厅或套餐候选。支持可选链接，粘贴大众点评等分享文案自动提取名称和 URL；只有短链接而没有名称的内容需要补填名称，不依赖外部抓取代理。保存餐厅时尝试读取链接的 Open Graph/Twitter 预览图或直接图片，成功后显示在卡片上，并随活动复制或历史候选复用。目标网站需允许浏览器跨域读取；没有预览图、访问受限或读取超时时仍可正常保存。
- 历史餐厅按名称搜索，搜索结果注明原活动，可直接加入当前候选。
- 单选、多选、最多 N 项或不限项；显示票数、进度和投票者头像；候选下方的横向柱状图按得票排序，实时比较各餐厅票数。活动打开时每 3 秒同步当前活动，后台页面暂停刷新，自己的操作成功后立即更新。
- 创建者结束投票并确认餐厅：默认推荐最高票，并列时选择；也可指定任意候选或在结束投票后更换餐厅。确认结果保留为当时的餐厅信息，后续修改候选不会悄悄改变最终安排。
- 关闭活动后安排、候选、投票、评论均只读。历史活动可以浏览；复制活动保留安排、候选和投票规则，生成新活动并清空投票、评论、结果和编辑历史。
- 评论输入 `@` 自动展开伙伴下拉列表，继续输入昵称可筛选，支持鼠标选择和上下键、回车或 Tab 补全；候选来自已参与该活动的伙伴。头像和应用内昵称按 Tiana 用户 ID 保存，可上传图片或自动生成文字头像；上传图片在浏览器裁剪为 160×160。

## 运行要求与身份

本模板运行在 Tiana 线上托管 Web 页面。运行时需要提供 `window.tiana.auth`、`window.tiana.connection()` 和同源 `./_tiana/session` 的 Tiana Web 运行时，SQLite 使用 `hrana-v3`，并支持 JSON 与 FTS5。会话的 `user.user_id` 是稳定身份；应用不保存登录凭据。

参与者先接受团队邀请，再使用各自的 Tiana 账号登录并选择应用所属租户，打开同一个 Web 应用。该租户的有效成员共享应用及其绑定的 SQLite；投票、评论、头像和活动创建者仍按各自的 `user.user_id` 区分。无需分享访问 Token，也无需在模板中配置租户 ID 或成员名单。

目标环境需要已部署租户成员共享能力。登录租户与应用所属租户不一致时，按页面提示重新登录并选择正确租户。部署后应使用两个真实成员账号验证共享访问；下方浏览器夹具验证的是应用协作逻辑。

`@` 是活动内的文本提及，不会发送站外通知。使用已参与当前活动的账号记录作为选择列表。

## 初始化与发布

1. 读取根目录 `metadata.json`，由 Agent 为本次应用创建 SQLite 和 Git 实例，或核实用户指定的已有实例。
2. 将 `source.json` 中两个占位符替换为实际实例 ID。
3. 对目标 SQLite 执行 `schema.sql`。初始库为空，由用户在页面创建活动，不包含虚构参与记录。
4. 执行 `npm ci`、`npm test`。提交干净源码并推送至用户 Git，核实远端完整提交。
5. 执行 `node scripts/build.mjs <完整源码提交号>`。输出 `dist/assets/app.js`、`dist/assets/app.css` 及本地项目参数；构建参数中的 commit 用于记录源码出处，具体管理命令以当前 CLI 帮助为准。
6. 创建 Web 时指定 `--entry assets/app.js` 并绑定实际 SQLite/Git 实例。使用 `tiana web publish WEB_ID --dir dist --json`，随后查询 `web status` 核实实际生效摘要。

原始项目使用 React、Vite、Lucide 图标及 Tiana 动态账号 SDK。字体通过 Google Fonts 加载 Noto Sans/Serif SC，网络不可用时使用系统字体。

## 数据与协作

`dining_events` 每行保存一场活动的安排、候选、投票、讨论和历史。修改先读取指定活动，再使用 revision 条件更新整行；并发冲突提示用户查看最新内容后重新提交。写入响应丢失时只读取确认，不自动重发。`dining_profiles` 保存应用内头像和昵称。

按状态与创建时间建立索引，活动列表每页 20 项。`dining_search` 是餐厅名称的 FTS5 搜索索引，由 SQLite 触发器与活动更新一同维护；逐字符索引支持中文短词，匹配候选后再核对实际名称的连续子串，不遍历全部活动。每次搜索按需返回 20 个候选活动并支持继续查找。活动历史和头像均不作为登录凭据。

## 验证

```sh
npm test
npx vite build
npm run test:browser
```

浏览器测试使用 Playwright Chromium 和 Node.js 22 的 SQLite，执行真实 SQL与 SDK 编解码，验证两个模拟账号的投票同步、评论 @、规则设置、最终餐厅改选、刷新持久化、关闭、复制、历史搜索和手机布局。首次使用 Playwright 时按其提示安装 Chromium。截图写到忽略的 `.artifacts/`。这套夹具独立于真实 Tiana 账号和数据库。
